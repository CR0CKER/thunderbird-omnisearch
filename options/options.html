Search interface

Either way, open search with the toolbar button or the Alt+S shortcut. The centered window grows as results appear; press Esc to dismiss it. In tab mode each button click / shortcut opens a fresh, independent search tab so you can run different queries side-by-side.

Search behavior

When off (the default), the popup closes as soon as you open a result.

Off by default. When on, OmniSearch keeps its index in memory so reopening search is instant instead of briefly reloading. Uses a little more memory and battery in the background.

Accounts to index

Unchecked accounts are excluded from search.

Off by default — Junk and Trash are kept out of search.

Off by default for privacy. Encrypted emails are indexed by subject/sender only, so their decrypted text is never written to the on-disk index. Turn this on to make their bodies searchable — their decrypted content will then be stored unencrypted in the index.

How much of each email's body is indexed (after quoted replies are removed). Smaller keeps the index lighter, so it loads faster and uses less memory — important on machines with limited RAM. Larger makes more of very long emails searchable. Changing this needs a rebuild.

Index

Rebuild re-indexes all of your mail from scratch. Verify & repair checks the index against your folders and fixes any drift — removing stale entries and indexing anything missing. Clear index deletes the search index from disk — including the decrypted contents of any encrypted emails you opted to index. Search stays empty until you rebuild.
